# Try Dental Fee List Builder and share what would make it more useful

This free browser tool is for dental practice managers. Prepare a clear fee list using your practice’s approved prices, price ranges and notes.

[Open the tool](https://dentist-web-design.github.io/dental-fee-table/). No coding knowledge, installation or account is needed. Start with the fictional example, or fill in the labelled fields with your own information. A readable fee list for internal approval or your website supplier.

Feedback about unclear questions, missing practical options or mobile usability is welcome here. Please use fictional information in public examples and keep customer or confidential details out of this discussion.

This formats information you supply. It does not set fees, recommend treatment or verify clinical and regulatory wording.

Maintained by [Dentist Web Design](https://dentistwebdesign.uk/), operated by JW Digital Services Ltd. The original developer helpers are still available in the repository, but they are not needed to use the browser tool.
